## Principle: organic-first unless there's a real budget

For a project with no marketing budget, the right sequence is organic validation before any
paid spend — running ads before the actual visit→install→paid conversion rate is known
means there's no way to tell if an ad channel is working or if the whole funnel is broken.
See [06-revenue-projections.md](06-revenue-projections.md) for the funnel this depends on.
If this project *does* have a real budget, say so explicitly here and adjust the channel
order accordingly — don't default to "no budget" without checking.
