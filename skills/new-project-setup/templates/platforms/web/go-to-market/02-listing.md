# Landing Page, Directory Listings & SEO

Parent plan: [MASTER_PLAN.md](MASTER_PLAN.md). Positioning basis:
[01](01-positioning-and-niche.md).

A web product has no store search doing discovery for it — the landing page *is* the
listing, and organic search plus a handful of directories (Product Hunt, niche tool
directories, relevant subreddits' wikis) are the closest equivalent to ASO. Someone
searching the niche's own pain-point phrase is already sold on the concept; they just need
to land here instead of on an incumbent.

Don't start this doc's copy until the name ([01](01-positioning-and-niche.md)) and pricing
([03](03-pricing-strategy.md)) are locked — headline, domain, and call to action all
depend on both.

## Landing page structure

<!-- Order matters — above-the-fold is what most visitors ever see. -->

1. **Hook** — the positioning statement from 01, as the H1 or close to it.
2. **Primary call to action** above the fold, matching the pricing model from
   [03](03-pricing-strategy.md) (sign up / start trial / join beta / buy).
3. **How it works** — 3-4 short points, or a single worked example, translating the SPEC §2
   mechanics into plain benefit language. A concrete worked example with real-looking
   numbers often beats feature bullets.
4. **Who it's for / who it's not for** — name the niche directly; an explicit "probably not
   for you if…" filters as much as it attracts.
5. **Any genuine differentiator worth a dedicated callout** (privacy, price model, no
   account required, etc.) — stated plainly and re-verified against the code at ship time.
6. **Repeat the call to action** at the bottom, plus support/contact and legal links.
