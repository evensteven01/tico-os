# tico-os

This repo is a Claude Code plugin (see `.claude-plugin/plugin.json`) plus a portable `AGENTS.md.template` for other projects' house rules. See [README.md](README.md) for structure and usage.

When editing skills or agents here, keep frontmatter (`name`, `description`, and `model` where set) accurate — `description` is what Claude Code uses to decide when to auto-invoke a skill.
